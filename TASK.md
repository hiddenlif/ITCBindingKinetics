A session on an isothermal titration calorimeter produced a batch of experiments: for each, a titration of a ligand into a host solution and the same injections into buffer, with one set of heater pulses for the whole session. Write `/app/itcreduce.py`, run as `python3 /app/itcreduce.py BATCH_DIR REPORT_JSON`, which reads a batch directory and writes a JSON report with the dissociation constant, the molar enthalpy, the stoichiometry and the association rate constant of the binding in every experiment. `/app/MANUAL.md` covers the instrument, the files and the report. `/app/worked/` is a batch from an earlier session with the values the lab reported for it. The batch in question is a different one, and every experiment in it is graded on its own.
